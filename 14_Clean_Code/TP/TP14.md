## Deskripsi

Kode awal memiliki terlalu banyak tanggung jawab dalam satu fungsi. Fungsi fetchOrderDetails() melakukan request API, memanipulasi DOM, mengatur modal, dan menangani event listener sekaligus. Hal ini melanggar Single Responsibility Principle (SRP).

Refaktorisasi dilakukan dengan memecah fungsi menjadi beberapa fungsi kecil yang memiliki satu tanggung jawab. Selain itu, penggunaan async/await membuat alur program lebih mudah dibaca dibandingkan chaining .then().

Hasil refaktorisasi membuat kode lebih modular, mudah dipelihara, dan lebih sesuai dengan prinsip Clean Code.
