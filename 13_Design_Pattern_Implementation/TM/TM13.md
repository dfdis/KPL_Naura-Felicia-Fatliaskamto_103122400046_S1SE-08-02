## Deskripsi
Menurut saya, Event Delegation adalah teknik dalam JavaScript yang digunakan untuk menangani banyak event dengan hanya menggunakan satu event listener pada elemen parent. Teknik ini memanfaatkan konsep event bubbling, yaitu ketika sebuah event terjadi pada elemen anak, event tersebut akan diteruskan ke elemen induknya. Dengan cara ini, kita tidak perlu memasang event listener pada setiap elemen secara terpisah.

Kelebihan utama Event Delegation adalah membuat kode lebih efisien dan mudah dikelola. Misalnya, jika terdapat banyak tombol dalam satu container, kita cukup memasang satu event listener pada container tersebut dan menggunakan event.target untuk mengetahui tombol mana yang diklik. Teknik ini juga sangat berguna untuk elemen yang dibuat secara dinamis karena elemen baru tetap dapat ditangani tanpa perlu menambahkan event listener lagi.

Menurut saya, Event Delegation merupakan teknik yang penting dalam pengembangan web karena dapat menghemat penggunaan memori, meningkatkan performa, dan membuat kode lebih rapi. Oleh karena itu, teknik ini sering digunakan pada aplikasi JavaScript modern yang memiliki banyak elemen interaktif.
