### user.controller.js

```javascript
const UserServices = require('../services/user.services')

exports.register = async(req,res,next)=>{
    try {
         const {email,password,nama} = req.body;

         const successRes = await UserServices.registerUser(email,password,nama);

         res.json({
            status:true,
            success:"User berhasil diregistrasi"
         });

    } catch (error) {
        throw error;
    }
}
```

### user.services.js

```javascript
const UserModel = require('../model/user.model');

class UserService {
    static async registerUser(email,password,nama){
        try {
            const createUser = new UserModel({email,password,nama});
            return await createUser.save();
        } catch (err) {
            throw err;
        }
    }
}

module.exports = UserService;
```


## Deskripsi
Pada file user.controller.js, fungsi register() menerima data pengguna berupa email, password, dan nama dari request body. Setelah itu controller memanggil method registerUser() pada UserServices untuk menjalankan proses registrasi. Controller tidak berinteraksi langsung dengan database sehingga tanggung jawabnya tetap sederhana, yaitu mengelola request dan response.

Pada file user.services.js, class UserService berisi logika bisnis untuk registrasi pengguna. Method registerUser() membuat objek UserModel baru dan menyimpannya ke database menggunakan method save(). Dengan adanya service layer, seluruh proses bisnis terkait pengguna dapat dipusatkan pada satu tempat sehingga lebih mudah dikelola dan dikembangkan.

Penerapan Service Layer Pattern memberikan beberapa keuntungan, antara lain meningkatkan keterbacaan kode, memisahkan tanggung jawab setiap komponen (Separation of Concerns), memudahkan pengujian (testing), serta mempermudah pemeliharaan dan pengembangan aplikasi di masa mendatang.
